Ladybird Windows Autobuilds

Unofficial repository providing automated native Windows (.exe) binaries for the Ladybird web browser. These weekly builds are compiled directly from the upstream master branch using GitHub Actions.

⚠️ Warning: These are automated native Windows builds tracking the Ladybird `master` branch. As native Windows support is highly experimental, most builds are expected not to work or may crash.
